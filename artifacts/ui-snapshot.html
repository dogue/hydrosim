TRAINING GUIDE

Follow the oil.

Build a circuit, operate its valves, and see how flow and load create pressure.

Try the demonstration

  1. Press Run. The tandem center sends pump flow back to tank.
  2. Select Extend below DCV1. Watch the cylinder and return path.
  3. Select FC1 and reduce its flow limit. The cylinder slows.
  4. At full stroke, watch RV1 relieve at 1,500.0 PSI.
  5. Select Retract to reverse the work ports.

Select a component to edit its label, adjust settings, and inspect live readings. Pressure without moving dots means static oil.

The demo pump is enabled. Run/Pause controls simulation time; the pump has its own start/stop control.
